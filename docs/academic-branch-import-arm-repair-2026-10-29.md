# Branch-specific pupil imports and reusable arms — 29 October 2026

Pupil membership CSV imports used an unscoped `listSchoolCollection('students')` in addition to the selected branch's pupil list. A matching admission reference anywhere in the organisation stopped the import. The importer now resolves profiles and document-name collisions only within the selected branch and school section. New profiles retain their branch/section path, incomplete-profile and pending-parent-onboarding flags. No foreign profile, parent link, credentials, membership or score is copied or altered. Same-scope conflicts, duplicate CSV rows, conditional writes and existing membership/transfer safeguards remain enforced.

Reusable arm creation now reuses an active definition with the same name and code, including definitions whose legacy document ID differs from the current generated ID. A different capacity in a create request cannot overwrite its saved capacity. Explicit editing remains available. Conflicting codes, inactive records and ambiguous duplicates receive an actionable message. Applying a reusable arm recognises an existing classroom with a legacy arm ID and keeps its settings and history, instead of creating a second classroom. Catalogue usage counts recognise those classrooms too.

Read-only production checks confirmed EXCELLENCE in The Lord's Garden Primary with capacity 25 and code EXC, under an immutable ID ending in `dis`. MERIT, code MER, capacity 28 occupies the generated ID ending in `exc`. Earlier renaming left those IDs in place, so creation must match current names/codes rather than assume an ID still represents its original name. Both definitions are preserved. No classrooms have yet been created from them in that branch. No live pupil, classroom, score or catalogue records were changed during investigation. The user's original CSV was not available and was not replayed against production.

Validation: nine behavioural regressions exercise cross-branch and cross-section references, preserved foreign records, no unscoped pupil read, no-write retries, same-scope ID collisions, duplicate CSV rows, branch-specific Excellence creation, legacy/renamed IDs, case-insensitive names, capacity preservation, inactive/ambiguous definitions and classroom reuse. A delete/recreate test verifies that Delete physically removes the unused definition and immediately frees its name/code; no archived catalogue copy remains. The deletion audit and unrelated historical scores remain preserved. New definitions get a deterministic unused ID if renaming has occupied their generated ID; conditional creation prevents concurrent overwrites.
