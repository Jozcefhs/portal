# Dynamax v3.1.58

- Security audit logs stop creating redundant entries for successful billing and academic previews, photograph loads and verified payment retries. Actual changes, failed requests and permission denials remain auditable. Historical records are preserved and routine entries can be shown using the routine-activity checkbox on web and desktop.
- Apply active layout now refreshes and verifies the selected web scorebook before reporting success. Saved marks, zero scores, CBT evidence and score locks are preserved; unsafe migrations and conflicting changes are rejected.
- Card terminal preparation is available for school, faith and other organisation editions on web and desktop. It includes branch setup, general-income payment requests, verified receipts, recovery and date-filtered history.
- Card terminal payments remain disabled by the server deployment gate. Enabling a branch, creating requests and sending charges are blocked. This release does not activate hardware, charge cards, allocate school fees, top up wallets or fulfil store orders.

Update existing installations to v3.1.58 to receive the desktop controls. Existing scores, payments and records are preserved. Web repairs are delivered through the web deployment.
